### Возможности

- Синхронный текст для треков, у которых его нет в Яндекс Музыке, в том числе для загруженных пользователем
- Штатное отображение: текст открывается кнопкой в плеере, подсветка строк и оформление — как у Яндекс Музыки
- По желанию — замена текста, который уже есть у Яндекс Музыки, текстом из LRCLIB

### Установка

Установите аддон из вкладки «Каталог» на странице мода. После установки страница клиента перезагружается,
чтобы текст появился и у треков, которые уже были открыты.

### Настройки

| Настройка | По умолчанию | Назначение |
|---|---|---|
| Заменять и тот текст, что уже есть у Яндекс Музыки | включено | Если включено, для треков с собственным текстом Яндекс Музыки показывается текст из LRCLIB, когда он там есть. Если выключено, LRCLIB используется только для треков без текста |

### Принцип работы

Аддон проверяет треки, которые загружает клиент, и для треков без синхронного текста ищет его в LRCLIB по
названию, исполнителю и длительности. Результаты поиска сохраняются на устройстве: повторные запросы для уже
проверенных треков не выполняются, а тексты недавно найденных треков открываются даже при недоступности
LRCLIB.

Кнопка текста у ещё не проверенного трека становится активной сразу, не дожидаясь ответа LRCLIB. Если для
такого трека текста в LRCLIB не окажется, экран текста при первом открытии будет пустым, а при следующих
загрузках кнопка у этого трека отображаться не будет.

### Конфиденциальность

Для поиска текста в LRCLIB передаются название трека, имя исполнителя и длительность. Другие данные,
в том числе сведения об учётной записи, не передаются.

### Требования

YMDMod 0.2.0 или новее.
